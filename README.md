# HOW TO DEPLOY SITE

Deploying a PHP Website on Heroku
Follow these steps to deploy your PHP website on Heroku using the web interface:

1. Create a Heroku Account
Go to https://www.heroku.com/ and sign up or log in.

2. Create a New Heroku App
Click on "New" → "Create new app".

- Enter a unique app name.

- Choose a region (United States or Europe).

- Click "Create app".

3. Add PHP support

- You need to go to the Settings tab

- Click Add buildpack

- Add PHP

4. Upload Your Code to GitHub
Ensure your project is in a GitHub repository.

If your code is not on GitHub yet:

- Create a new repository on GitHub.

- Upload your project files.

5. Connect GitHub to Heroku

- In the Heroku Dashboard, go to your app settings.

- Navigate to the "Deploy" tab.

- Under "Deployment method", select GitHub.

- Click "Connect to GitHub" and authorize Heroku.

- Search for your repository and click "Connect".

6. Deploy the Application

- In the "Manual Deploy" section, select the correct branch (main or master).

- Click "Deploy Branch".

- Wait for the deployment to complete.

7. Open Your Website
Once deployed, click "View App" to access your website.
